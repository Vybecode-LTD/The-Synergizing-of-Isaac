# Game data

The one copy of the data the site runs on. The web app bundles it, the API reads it, and
`scripts/gamedata.py validate` checks it (CI runs that on every pull request).

| File | What | Edit it? |
|---|---|---|
| `items.json`, `trinkets.json`, `characters.json` | Roster: IDs, names, quality, stat changes, transformations, pools, starting items | **No.** Generated by `python scripts/gamedata.py build` from `sources/` |
| `synergies.json` | The curated synergy list (458 entries at import) | **Yes**, by hand. Names must match the roster exactly; `validate` says which don't |
| `sprites/items/NNN.png`, `sprites/trinkets/NNN.png` | 64x64 sprites, named by the game's own ID | Refreshed by `import-sources` |
| `sprites/characters/<slug>.png` | Character portraits carried over from the desktop app | By hand |
| `sources/` | The inputs `build` reads | Refreshed by `import-sources` |

## Where each fact comes from

| Fact | Source | Licence / status |
|---|---|---|
| Item and trinket IDs, names, effect line, stat changes, transformations, DLC | `sources/tracker-items.json`, copied unchanged from [Rebirth Item Tracker](https://github.com/Rchardon/RebirthItemTracker) at commit `7ef885a` | BSD-2-Clause; notice kept in `sources/TRACKER-LICENSE.txt` |
| Item and trinket sprites | Same repository, `collectibles/` | The artwork is the game's (Nicalis / Edmund McMillen); used as an unofficial fan reference |
| Quality (0-4), item pools, starting items | `sources/game-facts.json`: numbers read out of the game's `items_metadata.xml`, `itempools.xml` and `players.xml` for Repentance 1.7.9b (mirror: `Derugon/TBoIR-resources`, folder `1.7.9b.J835/resources-dlc3`). Only the extracted facts are stored, not the files | Facts |
| Synergy descriptions and ratings | Carried over from the desktop app's hand-curated list | **Not yet verified entry by entry** against the game or the wiki |

## What was wrong before (2026-11-24)

The desktop app's `items.json` was replaced, not patched: its Repentance IDs were scrambled (Birthright was
626; the game's ID is 619), 115 items and 18 trinkets were missing, 15 "trinkets" were really items or did
not exist, quality values were unreliable (The Sad Onion was 1; the game says 3) and pickup quotes were
partly invented. Nothing from that file is used here. The desktop app under `src/` still reads its own old copy.

Names fixed while migrating the synergy list: `Satanic Bible` -> `The Satanic Bible`,
`Jacob & Esau` -> `Jacob and Esau`. Three entries referred to the trinket `Cancer`, which the old trinket
list lacked; they resolve now.

## Honest gaps

- Character base stats (damage multiplier, speed, health) are not in the data: the game hard-codes them and no
  machine-readable source was found. The site shows starting items only.
- Starting items come from `players.xml`, which leaves out items the game grants in code (Isaac's D6 after
  its unlock, for example).
- Repentance+ balance changes after 1.7.9b are not reflected in quality or pools.

## Refreshing

```
git clone --depth 1 https://github.com/Rchardon/RebirthItemTracker <tmp>/tracker
python scripts/gamedata.py import-sources --tracker <tmp>/tracker --facts <dir with quality.json, players.json, pools.json>
python scripts/gamedata.py build
python scripts/gamedata.py validate
```
